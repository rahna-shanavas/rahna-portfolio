01 / FINAL YEAR PROJECT

HydroSave+

AI-Powered Smart Water Monitoring System with Quality

2025 – 2026

HydroSave+ is an IoT-based smart water monitoring system designed to monitor water usage, tank levels and water quality. The system collects real-time data using sensors and sends it to a web dashboard for monitoring and visualization.

It also uses a Machine Learning model to predict future water demand based on usage patterns, helping users understand and manage water consumption more efficiently.

Key Features

  • Real-time water flow and tank level monitoring.
  • Water quality monitoring using TDS and turbidity sensors.
  • Temperature monitoring.
  • Web dashboard for displaying sensor data.
  • OLED display for local water consumption information.
  • Machine Learning-based water demand prediction.
  • Water quality alerts based on sensor readings.

Technologies & Tools

Python Machine Learning Random Forest Arduino ESP32 MySQL HTML CSS JavaScript IoT Sensors MQTT

02 / MINI PROJECT

AISAT Super League (ASL) Management System

Football League Management Web Application

2024 – 2025

The AISAT Super League Management System is a web-based application developed to simplify the management of university-level football tournaments.

The platform provides a centralized system for managing teams, players, match schedules, scores and league standings. It also allows fans to view match updates, participate in polls and create fantasy football teams.

Key Features

  • User registration and login.
  • Authentication and role-based access.
  • Separate admin and user dashboards.
  • Team and player management.
  • Match scheduling and score updates.
  • League standings and rankings.
  • News and match updates.
  • Fantasy football team creation.
  • Fan polls and participation.
